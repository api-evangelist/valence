# Valence

Valence (Valence OS) is an early-stage mental-healthcare company backed by 500 Global, building continuous care that bridges the gap between therapy sessions. Its site describes an evidence-based system grounded in peer-reviewed research on mental-health trends, attrition factors, between-session care, and AI-augmented clinical support.

Valence publishes no developer portal, API documentation, or machine-readable API artifacts as of July 2026 — https://werevalence.com

Note on a name collision: the original stub conflated three distinct companies named Valence. This profile is the 500 Global portfolio company at werevalence.com. Bessemer Venture Partners backs a different Valence (https://www.valence.co/, AI leadership coaching) and Y Combinator backs a different Valence (https://valence.trade, prediction-markets trading).
